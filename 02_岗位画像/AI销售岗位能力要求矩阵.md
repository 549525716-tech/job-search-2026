## 六、下一步使用方法

1. 简历首页只放排名前 6 且自己能举证的能力。
2. 每补 5 到 10 条 BOSS 岗位样本后，运行 `npm run capability:matrix && npm run gap:resume && npm run report:full`。
3. 如果某个能力只有公开趋势证据、缺少 BOSS 证据，先不要写成强结论，只作为采样方向。
4. 简历改写时优先使用“客户类型 + 场景 + 动作 + 结果”的证据格式。
