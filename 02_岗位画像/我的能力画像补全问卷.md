# 我的能力画像补全问卷

更新时间：2026-06-30

## 一、本质判断

这份问卷不是为了写得更好看，而是把 AI 销售岗位市场要求转成你的个人证据库。只有把客户、场景、动作、金额、结果和证明材料补齐，系统才能判断你适合 AI 软件销售、售前解决方案、硬件/智算/半导体销售，还是销售管理岗。

当前最大的矛盾是：市场岗位要求已经能拆出来，但你的真实能力画像还没有足够数据，所以简历 Gap 只能停留在“待补证据”。

## 二、先填最关键的 12 个问题

| 优先级 | 问题 | 填写口径 |
| --- | --- | --- |
| P0 | 你过去最能代表销售能力的 3 个项目是什么？ | 客户是谁、行业是什么、你负责什么、结果是什么 |
| P0 | 最大单客户、单项目或年度合同额是多少？ | 写金额区间也可以，例如 10万、50万、100万+ |
| P0 | 是否做过大客户/KA 开发？ | 决策链、关键人、周期、竞品、推进动作 |
| P0 | 是否做过 AI、SaaS、云、数字化、广告技术或企业服务产品？ | 产品名称、客户场景、你怎么讲价值 |
| P0 | 是否参与过需求调研、方案宣讲、Demo、POC、投标或述标？ | 次数、客户角色、结果 |
| P0 | 是否对合同、回款、续费、增购负责？ | 合同额、回款额、达成率、续费率 |
| P0 | 做过哪些行业客户？ | 制造、政企、教育、金融、互联网、本地生活、汽车、医疗等 |
| P0 | 是否带过团队或管理销售过程？ | 团队人数、目标拆解、达成率、机制建设 |
| P1 | 是否做过渠道、代理商、生态伙伴？ | 伙伴数量、激活、联合商机、渠道收入 |
| P1 | 是否接触过硬件、服务器、IDC、云、芯片、算力项目？ | 产品/客户/项目/渠道/交付链路 |
| P1 | 你更想主攻哪条路线？ | AI软件落地、硬件/算力/半导体、行业解决方案 |
| P1 | 哪些岗位/行业/城市/薪资不能接受？ | 作为投递边界，不写进简历 |

## 四、简历最需要补的证据顺序

1. 大客户/KA 开发：客户、决策链、周期、金额、推进动作、结果。
2. AI/大模型产品理解：产品能力如何对应客户业务场景。
3. 方案宣讲/解决方案：需求调研、方案页、Demo/POC、客户汇报。
4. 回款/合同/商务闭环：合同额、回款、续费、客单价、达成率。
5. 行业场景理解：制造、政企、教育、金融、互联网等具体场景。
6. 项目推进/跨部门协同：售前、产品、交付、法务、财务如何配合。
7. 渠道/生态合作：伙伴数量、联合商机、渠道收入。
