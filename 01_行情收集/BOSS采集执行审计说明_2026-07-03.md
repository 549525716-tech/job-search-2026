# BOSS采集执行审计说明

更新时间：2026-07-03 Asia/Shanghai

## 一、为什么会打开很多个“BOSS登录安全入口”

这不是正常的采集结果，而是登录态交接流程被重复触发后的副作用。

当前项目为了避免直接用自动化控制 BOSS，`auth:boss` 不会直接打开 BOSS 搜索结果页，而是生成并打开本地文件：

```text
/Users/MR/Documents/职场/01_行情收集/BOSS登录安全入口.html
```

这个本地页的作用只是提醒：先从 BOSS 首页进入，等登录态稳定后再站内搜索。它本身不访问 BOSS，也不会抓岗位。

如果任务中多次调用登录态检查、恢复流程或人工交接入口，而没有复用/关闭已有标签页，就会在 Chrome 里留下很多个相同的安全入口页。这个现象只能说明“登录交接入口被反复打开”，不能证明岗位采集已经发生。

## 二、什么不算采集

以下动作不能计入采集结果：

1. 打开 `BOSS登录安全入口.html`。
2. 打开 `about:blank`。
3. 只进入 BOSS 首页但没有岗位标题、公司、薪资、URL 进入本地数据表。
4. 只生成搜索链接但没有写入线索库或证据文件。

## 三、什么才算采集证据

一条岗位线索必须至少进入以下文件之一，才算可审计采集结果：

```text
/Users/MR/Documents/职场/01_行情收集/公开高薪销售岗位补充线索.csv
/Users/MR/Documents/职场/01_行情收集/BOSS公开页搜索证据_2026-07-03_云厂商高薪销售售前.md
/Users/MR/Documents/职场/01_行情收集/AI岗位机会汇总.md
/Users/MR/Documents/职场/01_行情收集/市场能力需求看板.md
```

最小证据字段包括：

| 字段 | 要求 |
| --- | --- |
| 来源 | 例如 BOSS公开页、猎聘公开页、Michael Page |
| 公司 | 必须有明确公司名 |
| 岗位 | 必须有岗位标题 |
| 薪资 | 必须写入表格，不能只写“高薪” |
| 来源URL | 必须可追溯 |
| 证据说明 | 说明公开页看到了什么，不把公开线索冒充成详情页JD |

## 五、当前没有完成的部分

当前 BOSS 登录态详情页人工复核仍是：

```text
0/500 个段落可导入，估算岗位 0 条
```

这意味着：公开页线索已经入库，但 BOSS 登录后的完整岗位详情正文还没有由人工复制进复核收件箱，因此不能把这 514 条说成“已完成 BOSS 详情页采集”。

## 六、后续执行原则

1. 默认不自动打开 BOSS，不通过 CDP 批量控制 BOSS。
2. 不重复打开登录安全入口。
3. BOSS 只保留“首页手动低频搜索 + 人工复制详情 + 本地解析入库”的安全路径。
4. 每次新增线索必须同步更新薪资、来源URL、证据说明和市场判断。
5. 如果恢复自动打开，也必须只在用户确认后使用低频节流：首个立即打开，后续每个间隔 10-20 秒，并限制单次打开数量。
