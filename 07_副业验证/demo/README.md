# 报表到行动清单 · 合成演示

此样例是AI工作流服务中可确定计算的一个环节，复用本人内部工作流的展示思路；不是完整AI系统，不调用模型，也不证明商业效果。

```bash
node 07_副业验证/demo/run.mjs
```

查看 [输入](input.json) → [规则实现](run.mjs) → [保存的输出](output.json)。余额和日均消耗都是虚构数据，不含客户信息。输出含输入哈希，复跑可核对同样输入是否得到同样结果。

展示顺序：先说明使用者每天要决定什么，再展示三条输入；解释“余额还能用几天”，展示优先核实、正常观察和缺失数据三个分支；最后说明仍由负责人核实预算、数据和沟通动作。本样例不自动联络任何人。

正式试点需先明确真实输入格式、预算规则、数据权限、处理频率及验收，不能直接把这个演示当成已验收客户交付。
