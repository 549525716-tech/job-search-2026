## 当前口径

主业保留销售/KA、销售管理、市场营销、商务渠道生态、销售及商业运营；业务型售前按真实JD另评。排除客户成功、产品经理主岗。招聘人民币月薪区间上界达到20K进入机会池，固定底薪单独核验；薪资机会优先，其次看能力证据。管理与长期To B经验是加分方向，不是采集前置条件。

市场工作先扩行业、公司、渠道和岗位，再深入匹配。公司清单是起点，批次预算不是市场完成标准。未知薪资、陌生标题、未评分岗位保留。只有本轮重新读取来源，才能判断新增或变化。

副业先验证销售面试/带教辅导的小单；AI服务先验证一个报表到行动清单的付费任务。已有内部作品不等于外部订单，当前付费情况未知。获客资料可在本地准备，对外发送、发布和投递仍按具体授权执行。

## 日常入口

```bash
# 只用已保存证据重建岗位报告，不代表重新联网
npm run careers:decision:report

# 离线准备下一批来源任务；范围、准入和待续见生成的批次
npm run careers:discovery:prepare

# 执行时必须指定已检查的冻结批次
npm run careers:discovery:run -- --batch <批次ID>
```

官网模块说明见 [careers/README.md](careers/README.md)。独立公开来源可以继续，BOSS/猎聘自动接管仍隔离；不得刷新普通登录标签或切换日常Chrome。采集遵守共享串行队列及已有停源记录。
