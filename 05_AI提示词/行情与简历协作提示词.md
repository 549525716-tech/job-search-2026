# 行情与简历 AI 协作提示词

## 零、两步法总控提示词

请固定按“两步法”处理，不要先看岗位 JD 再倒推包装简历。

第一步：先总结我自己。请基于我的简历和事实证据，提炼我当前真实情况：

1. 我现在的核心身份是什么。
2. 哪些能力有直接证据。
3. 哪些能力只是可迁移证据。
4. 哪些能力目前不能夸大。
5. 我的最强销售、客户经营、销售管理、AI 工具实践证据分别是什么。

第二步：再对比市场。请基于岗位样本、薪资和岗位要求，判断：

1. 市场正在为什么能力付费。
2. 我的直接证据能覆盖哪些要求。
3. 我的可迁移证据能覆盖哪些要求，但需要怎样转译。
4. 我的硬缺口在哪里。
5. 每个 P0 缺口对应的最小补强产出是什么。
6. 下一版简历应该前置、弱化、新增或删除什么。

输出必须分成两部分：

1. **个人画像总结**：只讲我的真实情况和证据边界。
2. **市场岗位对比**：再讲匹配度、能力 gap 和补强动作。
