# 个人事实输入核查

核查依据：现有个人画像（2026-09-07版本）与用户在本对话随后确认的求职偏好。本文件不是新的市场匹配结论，也不是业绩数据审计。

## 使用顺序

1. 原始事实读取 `02_岗位画像/data/我的能力画像.json` 与 `我的当前情况总结.md`。
2. 当前求职偏好读取 `careers/config/preferences.json`，不沿用画像中的历史“管理优先”或未确认薪资字段。
3. 对每条完整JD自上而下解释岗位产出与硬门槛，再判断事实是否能证明。不能以关键词相似度替代证据判断。

## 必须保留的边界

- 懂车帝210家商户是个人客户盘；跨区域分工、复盘和督办不能写成跨区域人事直管。
- 乐道和特斯拉同时直管10人，累计带教21人是另一口径；晋升推荐为参与，不是审批权。
- AI地图团队全员使用，但团队具体人数待补；150%效率改善和每天约2小时节省是个人陈述及个人测量，不是团队审计结果。
- 原始AI项目可证明业务问题分析、工具设计和内部应用，不证明AI产品客户签约、生产级POC或工程型FDE交付。
- 合同金额、ARR、回款、留存和企业IT采购链路没有新增可靠证据，保持缺口。
- 用户已要求删除“4到10台/月”的对外展示。原始档案保留审计历史，新的报告建议和简历内容不得重新引用。
- 当前画像中的旧市场研究更新于7月，不代表本次招聘状态。历史项目数字也不当成9月重新测量的数据。
- 若同一指标在旧细项和最新本人陈述之间冲突，采用最新已确认口径并保留冲突说明，不能挑选较高数值。

## 暂不确认的硬条件

差旅接受度、异地安排、海外工作资格、英文工作水平、生产代码交付能力及真实AI销售合同金额不能默认满足。缺少证据的硬条件即使总评分达到80，也不能自动建议原简历直接投递。
